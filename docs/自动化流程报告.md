## 一、形态决策(A/B/C)

任务卡三选一,**选 B(独立壁纸服务)+ 原创 UI → 原创档**:

| 形态 | 判定 | 理由 |
|---|---|---|
| A. TOS Web 桌面动态背景 | ✗ | 改 TOS 自家 UI,审核可能视为"修改平台"/工具类,档位风险高 |
| **B. 独立壁纸服务** | **✓** | NAS 存壁纸库 → 局域网任意浏览器/平板/壁纸客户端拉流,天然 NAS 场景;原创 UI/交互 → 冲 200 元档(参照 AdWall) |
| C. Windows 客户端打包 | ✗ | TOS 是 NAS,无桌面场景,指南禁桌面 GUI |

WallLoop 实现要点:
- **双监听面**:管理面 `127.0.0.1:18241`(面板+写 API,仅 TOS nginx 反代可达,`/wallloop/` iframe 悬浮窗);公开面 `0.0.0.0:18240`(播放器 `/play` + 媒体流 + 只读 `/api/v1/now`,LAN 直连,写接口一律 404)
- **素材零打包**:不携带任何上游 CDN 素材(内网不可用+版权);壁纸由用户上传(mp4/webm/图片)或 ffmpeg 现场生成(mandelbrot 演示);ffmpeg 用 TOS 出厂自带 `/usr/bin/ffmpeg`
- **播单引擎**:rotation 定时轮换 / timeofday 昼夜槽位(day/night)/ shuffle,浏览器端 H.264 硬解,NAS 零转码压力

## 二、产线规则合规自查

| 规则 | 落实 |
|---|---|
| 查重第一道过滤 | 快照 1258 条(2026-11-18),`动态壁纸/壁纸/wallpaper/屏保/screensaver/背景图/live wall` **全部零命中**;VM 应用中心对照无壁纸/屏保类内置应用 |

| MemoryDenyWriteExecute | unit 中**明确缺席**(注释引用 go2rtc/owncast SEGV 教训);其余 TOS7 审核硬化项齐全(NoNewPrivileges/ProtectSystem=strict/ProtectHome/PrivateTmp 等) |
| 双架构强制 | x86_64 + aarch64 双 deb 均构建、入 release |
| HashRouter/子路径 | 管理面走 nginx `/wallloop/` 前缀剥离 + 相对路径资源;公开面独立端口无子路径问题 |
| 素材版权 | 不打包任何视频素材;演示壁纸由 ffmpeg 现场生成 |

  └─ dist.sh → wallloop_0.1.0_linux_{amd64,arm64}.tar.gz
